# Text engine

## Encoding (verified: decoded MESSAGE001/MESSAGE085/SPMES002003 lines read as natural Japanese)
- No Shift-JIS/UTF-16 text anywhere (jpscan of arm9 and DATA.SFS finds only kanji lists and graphics noise).
- **Code = glyph index in FONT_MES.NTFT** (DATA.SFS; 16x16 px, linear 4bpp rows of 8 bytes, 128 bytes/glyph, 0x56E glyphs; palette FONT_MES.NTFP). Ink is the low palette indices (1-3 core, up to ~8 anti-alias), 0xF border = outline.
  - byte `00..EF` = glyph `b`;
  - `F1+n, xx` (n = 0..4) = glyph `0xF0 + n*0x100 + xx`;
  - `FD` = new line, `FF` = end of string. Other F0/F6-FE codes: not yet seen in dialogue; list them during extract.
- Glyph order: 00-4F hiragana (あいう...ん, voiced, semi-voiced, small ぁぃぅぇぉっゃゅょ), 50-9F katakana (same order), A0-A9 0-9, AA-C3 A-Z, C4-DD a-z, DE-DF unread, E0-EB `!?♪~「」()…ー。、`, EC-56D kanji (~1154, in order of first use in the script: 行 下 私 神 加 護 正 義 聖 剣 ...). ヴ not located yet.
- `tbl/jp.tbl` is generated by `tools/mkjptbl.py` (kana, latin, punctuation read; kanji from `tbl/kanji.tsv` when it exists, else `{g:XXX}` placeholders). **Kanji readings are not done**: template matching against MS Gothic/Yu Gothic got at most 9/32 right (`tools/kanji_guess.py`), so read them from zoomed sheets (`tools/fontsheet.py`) with script context, then cross-check per the skill (§Recon item 4).
- Other fonts: FONT_SYSTEM.NTFT (0x1CC00), FONT_ITEM.NTFT (0xA500), FONT_END.NTFT (0x2C100), FONT_8X8. Order unchecked: confirm whether menus share FONT_MES codes.

## MESSAGE file layout (partly guessed)
- `u32 ?` (0 or 1), `u32 count` (1), `u32 table_off` (0xC) -> `u32 block_off` (0x10). Block: `u16 0x37, u16 0x21, u16 0x19`, then u32 values, then bytecode. **guess**.
- Bytecode references strings with `30 01 <u32 file offset>` (e.g. MESSAGE001 `30 01 40 02 00 00` -> 0x240 "さあ、行きましょう。"). Strings sit after the bytecode, FF-terminated. **verified for MESSAGE001's first strings**; other opcodes (0x33 xx, 0x20 0x36 ...) not yet mapped. Insertion must rewrite these u32 offsets (re-lay the string area, patch every `30 01` operand).
