# Style reference - character voices

Model: Atlus USA's Yggdra Union localisation (plain, modern, a little theatrical; royals formal, bandits rough).
Each row: who they are, the Japanese markers that carry the voice, and the English devices that must carry it.
A line any character could have said is a mistake. Boxes are small (about 22-26 letters a line, 2 lines): pick
short words, contractions, and drop filler the Japanese doesn't have, but never drop the voice marker.

## Approved examples (JP -> EN)
- Yggdra: 正義は聖剣の下にあり…\nさあ、行きましょう! -> `Justice lies with the Holy\nSword... Let us go!`
- Milanor: 腕が鳴るぜ。\nさあ、戦いの始まりだ! -> `I'm itching for this.\nLet the battle begin!`
- Dort: 待ちくたびれたわい。\nさて、行くとするかのう! -> `Kept me waitin', eh?\nWell, let's be off!`
- Pamela: うほっ!?\n続きやるのね!? -> `Ooh!? We're picking\nup where we left off!?`
- Nessiah: では、物語を再開すると\nしましょうか…フフフ -> `Now, shall we resume\nour story? Heh heh...`
- Corrected example: Flunky 先手必勝!\nで、合ってるよな? first came out as "Strike first! Is that right?" (flat). Better:
  `Strike first! ...That's\nhow it goes, right?` (keeps his muddled eagerness).
