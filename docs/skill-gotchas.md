# Skill gotchas (one line each: reference file, then the fact)

- references/setup.md: `fetch_emu.py` failed on this machine (504, then SSL CERTIFICATE_VERIFY_FAILED in urllib); `gh release download qa-2 -R minhnhattonthat/desmume` works. The zip unpacks to `tools/desmume/desmume-qa/`, which emu.py still finds.
- references/pipeline.md §Recon: kanji template matching (MS Gothic / Yu Gothic, 12-16 px, bbox-normalised correlation) got only 2-9/32 right on a bold outlined 16x16 4bpp DS font; budget for reading kanji by eye from sheets.
- references/platform-nds.md: Sting's DATA.SFS keeps its directory (hash, size, sector) inside arm9.bin, not in the archive; found by searching arm9 for the sector sequence of known file starts (stride-12 u32 1,4,6,7).
- references/graphics.md §Survey: some NDS games draw all 2D UI as 3D textures (NTFT/NTFP/NTFI = texel/palette/4x4 index); BG/OBJ VRAM dumps and vramfind.py find nothing. Tell: an index part exactly half the texel part (4x4 compression). Width isn't stored; a "smoothest row joins" guess over powers of two worked for every text texture.
- references/graphics.md §Survey: unknown file extensions in a hashed archive: log every name passed to the game's open call with an on_exec Lua hook during a boot run; it named 2,967 more files here (.PACK/.BI/.LTFT).
- references/emulator-qa.md §Visual QA: `codex exec -i` as a stand-in reviewer for a dispatched worker can hit a usage limit; budget to read sheets yourself (pack all small textures into ~1600x1800 pages; 2,497 textures fit in 29 pages).
- references/emulator-qa.md §Debug tool: NDS games that swap scenes by overlay often keep a scene table in arm9; searching arm9 for runs of u32s pointing into the shared overlay load address found it here (16-byte records init/main/exit/overlay id), and its reader gave the scene manager (current/next/phase): writing next + phase from Lua is a clean warp.
- references/emulator-qa.md §Debug tool: a warp that jumps straight past the game's New Game path skips the new-game init (map unowned); drive the real menu path by taps keyed on the scene id, then jump from the first in-game scene. L.press() from L.on_frame queues touches, and L.finish() ends a run as soon as the target is reached.
- references/emulator-qa.md §Visual QA: DeSmuME models card-read timing, so moving files in an archive (identity relayout) shifts load-dependent frames: a credits warp shot landed mid-fade on one layout and finished on the other at the same frame; compare relaid builds on static scenes or hold longer.
- references/pipeline.md §Recon: two-byte glyph codes need the draw loop, not a guess: here `F1..F9, xx` = (b-0xF0)*0xF0+xx (mla #0xF0), not *0x100. The wrong stride decoded kana fine and only showed as "codes past the font end" in late files; the tutorial on screen settled it.
- references/pipeline.md §Recon: reading ~1,700 16x16 kanji by eye from 160-glyph sheets (zoom 3) worked; a janome pass (kanji never inside a dictionary word, unknown compounds) then caught ~45 look-alike misreads (選/遥, 願/顔, 賛/貿). Key readings by bitmap hash so one reading fills every font.
- references/pipeline.md §Extract: a font can hold one kanji twice; give later copies a variation selector in the table so jp shows the char and encode(decode) still round-trips (tbl.py otherwise emits raw [XX] bytes for the second code).
- references/pipeline.md §Extract: a bold/display font with no fixed kana block (Yggdra FONT_ITEM) can be read for free when the same names exist in a known font: align the two record fields char by char (221 names gave 326/330 glyphs, zero conflicts), after fixing the known font's misreads first, since they propagate.
- references/pipeline.md §Extract: FF-splitting a pool merged a 4-byte code-read data block with the string after it (no FF between them); list every pointer target that lands strictly inside a split string and check each one.
- references/platform-nds.md (ITCM free space): when the ITCM autoload block has bss, code appended to its data lands in the bss the game uses; append zeros for the bss first, put the hooks after it and set bss to 0 (ndspy MainCodeFile save is byte-exact; only the module-params words change).
- references/platform-nds.md (keystone): keystone exposes no symbol table and prefix-assembling to find a label fails on forward refs; start the blob with a `b label` jump table and BL the sites to its fixed entries; reserve tables with `.space` at the end and splice the bytes in.
- references/pipeline.md §Marker: NDS games that copy one 16x16 glyph per character into a per-scene slot pool hang when English needs more glyphs than the Japanese (Yggdra ending: 32 dialogue slots). A per-letter VWF is not enough there: pack each line into 16 px cells at runtime, and widen the quad if the game drew 12 px of each slot. Bisect a marker hang by family, then file regex, then MARKER_SAME (same byte length) vs MARKER_GROW (file growth) to tell a length limit from a moved-pointer bug.
- references/emulator-qa.md §Debug tool: warp savestates made before a code change replay the old code (ITCM + main RAM); a shot from such a state showed every dialogue cell clipped to 12 px and looked like an engine bug. emu.py warns "state older than the ROM": regenerate states before judging any render.
- references/pipeline.md §Marker: an NDS game can draw one text family glyph by glyph from overlay code with its own fixed advance (Yggdra EDMES: ov9_15 `add r4,r4,#0xB` around a one-glyph draw call), so a VWF hooked in the arm9 run/dialogue routines misses it; log the callers of the single-glyph draw (callers.lua) on every text screen.
- references/pipeline.md §Checks (jp_left): with a one-byte glyph-index encoding, `--slots` built from every aligned pointer into the data area (tools/ptrslots.py) cut 17k noise runs to one real block (help text past a pool end); group hits by 4 KB bucket and read only buckets with long runs.
